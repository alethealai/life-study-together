# 李常受文集書目

資料來源為臺灣福音書房的[線上目錄](https://cwwl.twgbr.org/catalog.html)及其公開的 [catalog_data.json](https://cwwl.twgbr.org/catalog_data.json)。本專案只保存書名、章篇標題與頁碼，不包含正文。

2026-10-12 快照有 43 個年份／分類、138 個冊別、1,138 個書目／專題、9,715 個原始章篇條目。官方[套書介紹](https://www.twgbr.org.tw/pages/李常受文集)標示全套 139 冊；差異尚未釐清，不能將線上目錄快照宣稱為已核對完整的全套內容。

匯入時，在同一書目內按「標題＋頁碼」移除 156 筆完全重複條目，再排除 1,137 筆標題恰為「說明、原書說明、序、序言、前言、圖表」的前置內容，剩 8,422 個閱讀單元。原目錄混用章、篇、課、期等，這個數字是網站的計數口徑，不是出版社公布的總篇數。有 10 個書目在整理後沒有可計數單元，選單會停用。

書目 ID 由年份／分類、冊、書名的 SHA-256 前 16 碼生成，匯入會檢查唯一性。`functions/src/cwwl-data.json` 保存來源、日期、原始檔 SHA-256 及完整目錄；`cwwl-index.json` 僅含選單和後端驗證所需資料。章篇目錄在使用者展開時才載入。

重建方式：先下載官方公開 JSON，再執行 `python3 scripts/import-cwwl.py /path/to/catalog_data.json`。這是固定快照，不在使用者操作時向來源抓資料。更新快照前必須比對既有書目 ID、單元順序與數量；若既有單元變動，先制定進度遷移方案，不可直接覆蓋正在使用的計數口徑。

目前一座花園可選聖經、生命讀經、李常受文集；每種類型同時選一本書。沒有 `enabledTracks` 的既有花園沿用聖經及生命讀經。停用某類閱讀會隱藏並保留進度；更換該類書目則封存全體成員的舊進度，新書從 0 開始。文集每累積 3 個閱讀單元發放一個隨機 emoji；加入前起始位置不計獎勵，換書保留累積量與獎勵。
